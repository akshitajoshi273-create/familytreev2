## 🚀 HOW TO GET STARTED

### The FASTEST Way (5 minutes)

1. **Go to**: `d:\ws\python\familytree\familytreeproject`

2. **Read**: `QUICKSTART.md` (or see below)

3. **Setup Supabase** (5 min):
   - Go to https://supabase.com
   - Create account → New project
   - Copy credentials from Settings → API

4. **Configure** (.env file):
   - Rename `.env.example` to `.env`
   - Paste your Supabase credentials

5. **Run**:
   - Windows: `setup.bat` then `run.bat`
   - Linux/Mac: `chmod +x setup.sh && ./setup.sh && chmod +x run.sh && ./run.sh`

6. **Open**: `http://localhost:3000`

DONE! ✅
